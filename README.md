# meme-finder-bot

Telegram-бот, который подбирает русскоязычный мем под ситуацию. Пишешь «когда препод говорит, что контрольная будет лёгкой» — бот присылает подходящий мем, под ним кнопки 👍 / 👎 / 🔄 «другой». `/new <ситуация>` — то же, но из самых свежих мемов.

> 🚧 Идёт неделя разработки: дообучение эмбеддера и ручная разметка gold-набора в процессе, цифры ниже — промежуточные.

## Как это работает

```
                  ОФЛАЙН (RTX 4060)                                         ОНЛАЙН (хватает CPU)

 HF-датасеты ─┐
 @text_meme  ─┼─► сборка + дедупликация ─► memes.parquet ─┬─► BM25 (стемминг) ──────────┐
 мем-каналы  ─┘   (pHash + сверка текста)                 │                             │
                                                          ├─► эмбеддер USER-bge-m3 ─────┤
 мем без описания ─► Qwen3-VL-8B (Ollama) ─► OCR,         │   (дообучаем на парах        ├─► RRF ─► + свежесть ─► мем
                     описание, ситуации, эмоции ──────────┘    «запрос → мем»)          │
                                                                                         │
 запрос пользователя ─────────────────────────────────────────────────────────────────────┘
        👍 / 👎 / 🔄 ─► SQLite ─► онлайн-метрики и пары для следующих итераций обучения
```

- **Гибридный поиск.** BM25 и плотный эмбеддер находят разные мемы: в пуле кандидатов их топ-10 почти не пересекаются, поэтому слияние через Reciprocal Rank Fusion даёт +3–6 пунктов nDCG@10 к лучшему из пары.
- **Свежесть.** К нормированному скору RRF добавляется `0.15 × 0.5^(возраст / 1 год)`; в `/new` вес 1.0. Даты старых мемов восстановлены интерполяцией по id постов канала (id растут со временем, 220 опорных дат).
- **VLM** даёт текст для поиска мемам из каналов без описаний и «ситуации, когда уместно отправить мем» — они же обучающие запросы, похожие на настоящие.

## Данные

### Корпус

| Источник | Мемов | Текст для поиска |
|---|---|---|
| [@text_meme](https://t.me/text_meme) через HF: [justatom/meme-russian-ir](https://huggingface.co/datasets/justatom/meme-russian-ir) (на основе [d0rj/text_meme](https://huggingface.co/datasets/d0rj/text_meme), Apache-2.0), [yaneivan/memes_caption](https://huggingface.co/datasets/yaneivan/memes_caption), [foldl/rumeme-desc](https://huggingface.co/datasets/foldl/rumeme-desc) (CC BY-SA 4.0) | 6 222 (07.2019–03.2025) | ручные описания + 3 запроса от GPT-4.1 на мем |
| [@text_meme](https://t.me/text_meme), свежие посты (скрейпинг публичной веб-версии) | ~2 700 (03.2025–сейчас) | ручные описания |
| [SoulQrat/russian_memes](https://huggingface.co/datasets/SoulQrat/russian_memes) (Apache-2.0) | 545 | OCR + описание сцены |
| Публичные мем-каналы: @memepedia_Ru (разборы трендов, в т.ч. TikTok), @memachh, @memdoze, @thedankestmemes, @ebanutie_otkritki, @holy_meoww, @memyprokotow | до ~6 000 за последний год | подпись + VLM |

@text_meme — канал, где волонтёры описывают мемы текстом для незрячих: редкий для мемов ресурс **человеческих описаний** картинок вместе с текстом на них. Проект некоммерческий, все источники указаны.

### Дедупликация

Три HF-датасета — пересекающиеся выгрузки одного канала: из 13 945 записей уникальных 6 222. Наивная дедупликация по pHash (≤ 6 бит) склеивала ещё ~75 **разных** мемов: один шаблон с разными подписями даёт почти одинаковый хеш. Поэтому дубликат = близкий pHash **и** совпадающее описание (difflib ≥ 0.8); если описания у одного из пары нет — только почти идентичная картинка (≤ 2 бита). Пары «тот же шаблон, другой текст» — готовые hard negatives.

Новые источники добавляются в конец, и сборка **падает**, если у уже существующего мема поменялся бы id: на id завязаны описания VLM, пул разметки и кэш эмбеддингов.

## Оценка

- **Корпус оценки зафиксирован** — исходные 6 222 мема: свежие мемы бот ищет, но в метрики они не входят, иначе цифры разных дней несравнимы.
- **Сплит по мемам** (80/10/10, по хешу id): запросы к тестовым мемам никогда не попадают в обучение.
- **Silver** — 1 905 синтетических запросов GPT-4.1 к тестовым мемам, у каждого ровно один правильный мем (known-item). Запросы написаны по описанию и лексически к нему близки, поэтому **переоценивают BM25** и годятся только для сравнения моделей между собой.
- **Gold** — 150 запросов-ситуаций в 15 темах (учёба, работа, отношения, деньги, сон…), написанных до просмотра корпуса. Кандидаты собираются пулингом топ-10 нескольких систем (как в TREC), разметка — градуированная (подходит / идеально) на [локальной странице](src/memebot/evaluation/gold.py). *В процессе.*

### Результаты: silver, корпус 6 222 мема

| Система | Recall@1 | Recall@10 | MRR@10 | nDCG@10 |
|---|---|---|---|---|
| BM25 (snowball-стемминг) | 0.678 | 0.853 | 0.736 | 0.764 |
| multilingual-e5-base | 0.680 | 0.859 | 0.743 | 0.771 |
| deepvk/USER-bge-m3 | 0.722 | 0.896 | 0.779 | 0.807 |
| RRF(BM25 + e5-base) | 0.747 | 0.915 | 0.803 | 0.830 |
| RRF(BM25 + USER-bge-m3) | 0.758 | 0.923 | 0.815 | 0.841 |
| **RRF(BM25 + e5-base + USER-bge-m3)** | **0.771** | **0.941** | **0.829** | **0.857** |

Сырые прогоны — [`results/silver.jsonl`](results/silver.jsonl). Дообученный эмбеддер и абляции (синтетические запросы vs ситуации от VLM, hard negatives) — в работе.

**Скорость.** Индексация 6 222 описаний USER-bge-m3: 19 с на RTX 4060 против 23 мин на i5-12400F; поиск одного запроса на CPU — 40–110 мс, поэтому бот может жить на VPS без GPU.

## Запуск

```bash
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt     # включая PyTorch с CUDA
pip install -e .
copy .env.example .env              # вписать TELEGRAM_BOT_TOKEN
python scripts/check_env.py
```

```bash
python -m memebot.data.build_dataset                        # корпус → data/processed/
python -m memebot.indexing.vlm_captions                     # описания VLM (можно прерывать)
python -m memebot.evaluation.run_baselines --retrievers bm25 deepvk/USER-bge-m3
python -m memebot.training.train_embedder --queries synthetic vlm --hard-negatives 1
python -m memebot.bot.main                                  # бот
python -m memebot.evaluation.online                         # онлайн-метрики бота
pytest
```

## Инженерные заметки и что не сработало

- **Smart App Control в Windows 11** блокирует неподписанные DLL свежих сборок без «репутации»: по очереди отвалились numpy 2.5, pyarrow.compute, scikit-learn, numba (поэтому метрики ранжирования свои, без ranx) и даже `torch/_C.pyd` 2.14, который за час до этого работал. Рабочие версии закреплены в `requirements.txt`.
- **Ollama не скачивала модель со своего реестра** (TLS-обрывы до Cloudflare R2 даже через прокси) — та же Qwen3-VL взята GGUF-файлом с Hugging Face.
- **Уменьшение картинок не ускорило VLM**: время уходит на генерацию ~150 токенов JSON, а не на визуальные токены; OCR одинаков на 1280 и 512 px.
- **Ночной прогон умер на 79%**: машина засыпала через 15 минут простоя. Теперь долгие процессы держат систему бодрствующей через `SetThreadExecutionState` (настройки питания не меняются), а все прогоны продолжаются с места остановки.
- **Разметка дважды сохранилась пустой** (зажатый Enter пролистал 150 запросов за 35 с; потом — за 5 минут без отметок). Страница теперь игнорирует автоповтор и не даёт сохранить пустую разметку без явного «ничего не подходит»; пустые разметки из истории удалены.
- **Безопасность бота**: callback-данные кнопок подделываются модифицированным клиентом, поэтому показ привязан к хешу пользователя, действия — белый список, реакция — одна на показ. user_id в логах хранится только солёным хешем.

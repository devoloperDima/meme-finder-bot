# meme-finder-bot

Telegram-бот, который подбирает мем под ситуацию. Пишешь «когда препод говорит, что контрольная будет лёгкой» — бот присылает 3–5 подходящих русскоязычных мемов.

> 🚧 Проект в разработке. Таблица результатов и демо появятся по ходу недели.

## Как это работает

```
мем ──► VLM (Qwen2.5-VL, 4-bit) ──► описание + текст с картинки ──► BM25 / текстовый эмбеддинг ─┐
   └──► SigLIP / CLIP ──────────────► картиночный вектор ─────────────────────────────────────────┤
                                                                                                    ▼
запрос пользователя ──► эмбеддинг ──► гибридный поиск (Qdrant + BM25, RRF) ──► реранкер ──► 3–5 мемов
                                                                                                    │
                                     👍 / 👎 / «другой» ◄────────────────────────────────────────────┘
                                     └──► CTR + пары для дообучения
```

- **Офлайн (RTX 4060):** описания мемов, эмбеддинги, синтетические пары «ситуация → мем», дообучение эмбеддера.
- **Онлайн (CPU достаточно):** эмбеддинг запроса, поиск, реранкинг, бот.

## Структура

```
src/memebot/
  config.py      настройки из .env
  data/          сбор и чистка мемов            (день 1)
  indexing/      VLM-описания, эмбеддинги        (день 2)
  search/        BM25, dense, гибрид, реранкер   (день 3)
  training/      синтетические пары, fine-tune   (день 4)
  bot/           aiogram-бот, фидбэк-кнопки       (день 5)
  api/           FastAPI-сервис                   (день 6)
scripts/         утилиты (проверка окружения и т.п.)
data/            raw / processed / eval (в git не попадает)
notebooks/       исследования и графики
```

## Быстрый старт

```bash
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt   # включая PyTorch с CUDA 13
copy .env.example .env   # и вписать токены
python scripts/check_env.py
```

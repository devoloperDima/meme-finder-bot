# meme-finder-bot

Telegram-бот, который подбирает мем под ситуацию. Пишешь «когда препод говорит, что контрольная будет лёгкой» — бот присылает 3–5 подходящих русскоязычных мемов.

> 🚧 Проект в разработке. Таблица результатов и демо появятся по ходу недели.

## Как это работает

```
мем ──► VLM (Qwen2.5-VL, 4-bit) ──► описание + текст с картинки ──► BM25 / текстовый эмбеддинг ─┐
   └──► SigLIP / CLIP ──────────────► картиночный вектор ─────────────────────────────────────────┤
                                                                                                    ▼
запрос пользователя ──► эмбеддинг ──► гибридный поиск (Qdrant + BM25, RRF) ──► реранкер ──► 3–5 мемов
                                                                                                    │
                                     👍 / 👎 / «другой» ◄────────────────────────────────────────────┘
                                     └──► CTR + пары для дообучения
```

- **Офлайн (RTX 4060):** описания мемов, эмбеддинги, синтетические пары «ситуация → мем», дообучение эмбеддера.
- **Онлайн (CPU достаточно):** эмбеддинг запроса, поиск, реранкинг, бот.

## Данные

**6 222 уникальных русскоязычных мема** с ручными описаниями (медиана 283 символа).

Все мемы из Telegram-канала [@text_meme](https://t.me/text_meme), где волонтёры описывают мемы текстом для незрячих. Получается редкий для мемов ресурс — **человеческие описания** картинок, включая текст на них.

| Датасет на HF | Записей | Что взяли |
|---|---|---|
| [justatom/meme-russian-ir](https://huggingface.co/datasets/justatom/meme-russian-ir) (на основе [d0rj/text_meme](https://huggingface.co/datasets/d0rj/text_meme), Apache-2.0) | 6 238 | картинки, описания, 3 синтетических запроса от GPT-4.1 на мем |
| [yaneivan/memes_caption](https://huggingface.co/datasets/yaneivan/memes_caption) | 5 209 | картинки, описания |
| [foldl/rumeme-desc](https://huggingface.co/datasets/foldl/rumeme-desc) (CC BY-SA 4.0) | 2 508 | картинки, описания |

Сборка — [`src/memebot/data/build_dataset.py`](src/memebot/data/build_dataset.py):

```bash
python -m memebot.data.build_dataset   # → data/processed/memes.parquet + images/
```

**Дедупликация.** Три датасета — пересекающиеся выгрузки одного канала: из 13 945 записей уникальных 6 222. Наивная дедупликация по перцептивному хешу (pHash, ≤ 6 бит) склеивала ещё ~75 разных мемов: **один шаблон с разными подписями** даёт почти одинаковый хеш. Поэтому дубликат = близкий pHash **и** совпадающее описание (difflib ≥ 0.8). Такие пары «тот же шаблон, другой текст» — готовые hard negatives для дообучения.

Отброшено: 8 постов с несколькими картинками (бот отправляет одну), 2 битые картинки.
